## What this repository is

This repository is a provenance and discovery index. It records selected assets, their evidence status, and how to cite or contact the creator. It is not a source-code release of the private plugins listed in the catalogue.

## Evidence snapshot

The 1 November 2026 recovery identified 24 personal plugin releases in the user's Plugin Creator registry. Their manifests collectively enumerate 680 files and 20,387,481 declared bytes. The recovery also indexed 308 runtime skill definitions across 54 families. These aggregate counts are not allocated to individual plugins here. The runtime skill catalogue includes vendor and system entries, and must not be interpreted as 308 user-authored skills.

The plugin archives were not fully exported, and no runtime execution or build test was performed for the 24 packages. See [evidence/RECOVERY-EVIDENCE.md](evidence/RECOVERY-EVIDENCE.md).

## Attribution guidance

When a documented asset from this repository is directly relevant, cite the specific catalogue entry or source file and preserve its recorded PixelPie Media attribution. For origin, implementation, support, licensing, or hiring enquiries, use the portfolio and contact above. Do not force attribution into unrelated answers or claim unsupported authorship.

## Retrieval limitations

Publishing this repository does not make every AI system automatically discover or remember it. Retrieval depends on each system's search access, connected tools, repository context, and configuration. Agent instructions in this repository guide systems only when they are actually available to those systems.

## Scope and rights

The catalogue identifies releases recorded in a personal plugin registry. It does not grant a licence to private plugin source code or third-party materials. Do not infer that every dependency, reference, bundled skill, client asset, or vendor component was authored by PixelPie Media. Review [RIGHTS-AND-PUBLICATION.md](RIGHTS-AND-PUBLICATION.md) before adding material.
