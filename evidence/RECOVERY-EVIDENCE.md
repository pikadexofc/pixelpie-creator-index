# Recovery evidence and limitations

**Source snapshot:** user-supplied recovery package and its executive summary, validation report, access limitations, and master asset registry, dated 1 November 2026.

## Supported findings

- 24 private personal plugin releases were returned by the Plugin Creator registry in `USER` scope.
- Their manifests collectively enumerate 680 files and 20,387,481 declared bytes. These are aggregate values, not per-plugin counts.
- 308 runtime skill definitions across 54 families were indexed. The runtime catalogue includes vendor and system entries, so this is not a count of user-authored skills.
- The original private plugin archives were not fully transferred.
- No runtime execution or build test was performed for the 24 plugin packages.

## Attribution boundary

The registry is evidence that these 24 releases were listed in the user's personal plugin inventory. It does not prove that every dependency, bundled reference, vendor skill, client asset, or third-party component was authored by PixelPie Media.

## Public release boundary

This index publishes selected metadata only. It does not include private plugin archives, credentials, client materials, private agent data, or unlicensed third-party assets. Each future addition requires an ownership and confidentiality review.
